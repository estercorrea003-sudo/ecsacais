# ECSAÇAÍS 🍇

Projeto de uma página web para uma loja de açaí.

## Tecnologias utilizadas

* HTML5
* CSS3

## Sobre o projeto

O projeto foi desenvolvido para praticar a criação e estilização de páginas web utilizando apenas HTML e CSS, com foco em estrutura, layout, responsividade e design.

## Projeto

Site desenvolvido como projeto pessoal de estudo.
